## Featured Work

### MindfulClassroom Educational Web Platform
* **Live Deployment:** https://alexysgomez27.github.io/mindful-classroom-app/
* **Repository:** https://github.com/alexysgomez27/mindful-classroom-app
* **Architecture:** Semantic HTML5, Tailwind CSS, JavaScript, Web Audio API
* **Overview:** A responsive classroom wellness and focus application designed for instructional environments. Implements structured breathing timers (Box 4-4-4-4, Calm 4-7-8), procedural ambient pink noise, and dynamic Web Audio synthesizer alerts without external media dependencies.

### ApexCare Clinical Operations & Hospital Management System
* **Live Interface:** https://alexysgomez27.github.io/hospital-operations-portal
* **Repository:** https://github.com/alexysgomez27/hospital-operations-portal
* **Architecture:** PostgreSQL (ANSI SQL), Python, Tailwind CSS
* **Overview:** A 3NF normalized clinical relational schema tracking departments, attending physicians, inpatient bed allocations, and billing lifecycle management. Includes an executive bed-capacity telemetry dashboard and Python-driven reporting scripts for length of stay and payer mix metrics.
