## Featured Work

### NBA Player Efficiency & Contract Valuation Engine
* **Repository:** https://github.com/alexysgomez27/nba-performance-valuation
* **Architecture:** Python 3, Quantitative Modeling, Algorithmic Benchmarks
* **Overview:** A quantitative sports analytics and econometric evaluation model benchmarking on-court productivity against roster payroll cap allocations. Standardizes multi-category box production and advanced PER into a unified Performance Index to calculate fair market value and isolate high-surplus assets from cap drag.

### ApexCare Clinical Operations & Hospital Management System
* **Live Interface:** https://alexysgomez27.github.io/hospital-operations-portal
* **Repository:** https://github.com/alexysgomez27/hospital-operations-portal
* **Architecture:** PostgreSQL (ANSI SQL), Relational 3NF, Tailwind CSS
* **Overview:** A 3NF normalized clinical relational schema tracking departments, attending physicians, inpatient bed allocations, and billing lifecycle management. Includes an administrative bed-capacity telemetry dashboard and reporting queries for length of stay and payer mix metrics.

### MindfulClassroom Educational Web Platform
* **Live Deployment:** https://alexysgomez27.github.io/mindful-classroom-app/
* **Repository:** https://github.com/alexysgomez27/mindful-classroom-app
* **Architecture:** Vanilla JavaScript, Semantic HTML5, Tailwind CSS, Web Audio API
* **Overview:** A responsive classroom wellness and focus application designed for instructional environments. Implements structured breathing timers (Box 4-4-4-4, Calm 4-7-8) and procedural Web Audio synthesizer tone alerts without external media dependencies.
